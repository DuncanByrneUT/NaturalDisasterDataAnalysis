# Running the Script

To execute this project's Python script for analyzing US Natural Disaster Declarations, follow these steps:

1. **Ensure Python is Installed:**
   - You need Python 3.x installed on your system.

2. **Install Required Libraries:**
   - Open a terminal or command prompt and install the necessary libraries:
     ```bash
     pip install pandas matplotlib seaborn
     ```
   - Use a virtual environment for better dependency management.

3. **Download the Dataset:**
   - Download the dataset from Kaggle and place it in the same directory as your script or adjust the path in your code.

4. **Navigate to Script Directory:**
   - Use the command line to move to your script's directory:
     ```bash
     cd /path/to/your/script/directory
     ```

5. **Run the Script:**
   - Execute the script with:
     ```bash
     python app.py
     ```

6. **Check for Errors:**
   - Monitor the console for any errors. Common issues include:
     - Missing libraries: Install any missing dependencies.
     - Incorrect file paths: Verify the dataset path in your script.
     - Script errors: Look for syntax or logical errors in your code.

7. **View Results:**
   - Plots will appear in windows or be saved as files depending on your script's configuration. For interactive features or animations, run in a Jupyter Notebook environment if applicable.

Remember to ensure paths are correct, especially if you've used `sys.path.extend()` to include specific directories in your Python path.
